Pandey Foods is a cross-platform restaurant ordering and management application built using **Flutter** and **Dart**.

The application provides two different interfaces:

- Customer Restaurant Ordering System
- Restaurant Admin Management Panel

Customers can select their table, browse food categories, add items to their cart, place orders, select payment methods, and track their order status.

Restaurant administrators can manage orders, menu items, tables, QR codes, and view restaurant sales analytics.

## 📦 Order Tracking

Orders move through the following lifecycle:

Pending → Preparing → Ready → Served → Completed

Orders can also be cancelled by the restaurant administrator.

Each order stores:

- Order ID
- Table Number
- Ordered Items
- Quantity
- Subtotal
- GST
- Total Amount
- Payment Method
- Payment Status
- Order Status
- Order Time
- Special Instructions
